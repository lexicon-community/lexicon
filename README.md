# Lexicon Community schemas — moved

This repository is archived. Development of the `community.lexicon.*` lexicon schemas now happens on Tangled:

**https://tangled.org/lexicon.community/lexicons**

The history here is preserved as-is, and the schemas remain MIT licensed. Nothing that resolved against these schemas breaks: NSID resolution runs through the dedicated `@lexicons.lexicon.community` repository, not this repo. The [publishing and resolution guide](https://blog.lexicon.community/a/3mrnjw6qzzq23-publishing-and-resolution) explains how that works.

Where to find us:

- Website and governance: https://lexicon.community/
- Proposals and discussion: https://discourse.atmosphere.community/c/lexicon-community/31
- Blog and developer guides: https://blog.lexicon.community/
- Updates: [@lexicon.community](https://bsky.app/profile/lexicon.community)

If you were about to open an issue or pull request here: bring it to the forum or the Tangled repository instead. We would genuinely like to see it.
